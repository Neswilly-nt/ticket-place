# Ticket Place Project Documentation

## Overview
Ticket Place is an innovative platform that allows users to buy and sell tickets for various events, ranging from concerts to sports games. The project aims to provide a seamless user experience through an intuitive interface and robust backend architecture.

## Tech Stack
- **Frontend:** React, Redux
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Deployment:** Docker, AWS
- **Authentication:** JWT

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/Neswilly-nt/ticket-place.git
   ```
2. Navigate to the project directory:
   ```
   cd ticket-place
   ```
3. Install the required packages:
   ```
   npm install
   ```
4. Set up the environment variables as specified in the `.env.example` file.

## Setup
1. Start the backend server:
   ```
   npm run server
   ```
2. Start the frontend application:
   ```
   npm start
   ```
3. Navigate to `http://localhost:3000` in your browser to view the application.

## Features
- User registration and login
- Ticket purchasing system
- Search and filter events
- User profile management
- Admin dashboard for managing events and tickets
